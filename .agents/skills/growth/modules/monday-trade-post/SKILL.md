# Monday Trade & Post Workflow

## Overview

This skill outlines the strict workflow sequence for Monday live trading execution and result dissemination:

1. **Pre-check Verification**: Confirming the Sunday strategy validation ran successfully and passed its Deflated Sharpe Ratio gates.
2. **Minimal-Size Execution**: Performing a small/minimal size live trade via Alpaca for real-money execution verification.
3. **Split X Posting**: Posting an immediate high-level alert for the trade result, and scheduling strategy/validation metrics for midday.

## Dependencies

* **Sunday Validation Workflow**: Requires `logs/sunday_report.json` generated by the Sunday quantitatively optimized validation pipeline.

## Quick Start

To trigger the Monday trade and post workflow, run:

```bash
/Users/malcolm/.gemini/antigravity-ide/scratch/regime-trader/.venv/bin/python monday_workflow.py
```

## Workflow

### 1. Verification Precheck

* Read the validation results from `logs/sunday_report.json`.
* The `gameplan.status` must be `"PASSED"` and the `gameplan.dsr_score` must be $\ge 0.95$.
* If either condition is not met, the script will raise a `RuntimeError` and halt immediately, writing the failure state to `logs/monday_report.json`.

### 2. Live Order Placement

* The script checks Alpaca credentials and cash balances.
* If funds are present, it executes a live buy order with minimal sizing (`qty = 1` share) to safely verify real-money execution.
* If no cash balance is available, it falls back to Paper Trading.
* Strict 4.9% stop-loss bounds are verified and enforced (FINRA compliance).

### 3. Immediate Trade Posting

* Calls `publish_report.py`.
* Compiles and publishes a single, high-level tweet detailing the instrument, direction, and execution status without showing internal strategy metrics.

### 4. Midday Thread Scheduling

* Compiles the full strategy update, performance metrics, and optimizations.
* Saves the compilation to `logs/midday_x_post.json` with a scheduled midday trigger status for subsequent publishing.

## Common Mistakes

* **Sunday Report Missing**: Running the Monday workflow without first completing the Sunday validation cycle will cause immediate pre-check failure.
* **Excessive Size**: Submitting trades with larger quantities. The size must remain minimal (`qty = 1`) to ensure safety during connectivity checks.
