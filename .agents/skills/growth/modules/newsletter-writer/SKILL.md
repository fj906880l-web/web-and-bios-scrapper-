## 2. Hard Rules & Ethics Gate

Every execution of this skill must strictly satisfy all 11 cardinal ethics and editorial rules. **No exceptions are permitted.**

```
                                  ETHICS & EDITORIAL PIPELINE
  +-----------------------------------------------------------------------------------------+
  |  1. Verify Before Publishing  |  2. Two Independent Sources   |  3. Primary Source First|
  |  4. Epistemic Labeling        |  5. Zero Fabricated Data      |  6. Labeled Illustrations|
  |  7. Light Quoting (<25w)      |  8. Commercial Disclosure     |  9. Fail-Closed Policy  |
  |  10. Immutable Verification Log                              |  11. Corrections Protocol|
  +-----------------------------------------------------------------------------------------+
```

### The 11 Cardinal Rules
1. **Verify Before Publishing**: Every statement of fact, technical benchmark, or executive claim must be directly anchored to documentary primary or verified secondary evidence.
2. **Two Independent Sources Rule**: Any surprising, unconfirmed, or non-obvious claim requires corroboration from at least two distinct, non-affiliated sources. Syndicated reprints or blog summaries of the same press release count as one source.
3. **Primary Source Priority**:
   - *Tier 1 (Authoritative)*: Peer-reviewed papers, arXiv preprints, SEC regulatory filings (10-K, 10-Q, 8-K), patent grants (USPTO/WIPO), official open-source repository commits.
   - *Tier 2 (Corroborating)*: Audited corporate technical blogs, official engineering whitepapers, conference presentation recordings.
   - *Tier 3 (Discovery Only)*: Tech journalism, analyst notes, and social commentary. These are valid triggers for discovery, but invalid as final verification proof.
4. **Mandatory Epistemic Labeling**: Every claim, figure, or deduction must carry one of three standard epistemic tags:
   - `[Reported]`: Direct empirical observation, verified primary filing, or benchmark recorded under controlled conditions.
   - `[Claim]`: Corporate announcement, vendor press release, or experimental claim pending independent reproduction.
   - `[Analysis]`: Market Haven Consulting proprietary deduction, synthesis, or market impact thesis.
5. **Zero Fabricated Data**: Simulating metrics, presenting hypothetical model parameters as real data, or generating synthetic benchmarks is strictly prohibited.
6. **Labeled Illustrations**: Any image, diagram, or infographic generated or enhanced by AI must be explicitly captioned with `[AI-Generated Illustration]`. Telemetry charts must carry `[Telemetry Chart]`.
7. **Light Quoting & Fair Use**: Verbatim quotes must not exceed 25 words, must be strictly necessary for technical clarity, and must cite author and entity.
8. **Commercial Disclosure**: Any existing consulting relationship or financial interest between Market Haven Consulting and covered companies must be stated in the issue footer.
9. **Fail-Closed Publishing Policy**: If any claim fails the 4-point verification gate, it must be quarantined. If core assertions of an edition cannot be corroborated, the entire draft dispatch is halted and escalated to the editor.
10. **Public Verification Log**: Every published edition must produce an accompanying `verification_log.json` and human-readable verification markdown table documenting every claim, source, and audit score.
11. **Corrections & Retraction Protocol**: Any identified error in past editions requires a dedicated `[Correction]` banner placed at the very top of the succeeding edition.

### STEP 1: Temporal Research Window Calculation
Calculate temporal bounds in the `America/New_York` timezone:

- **Mode A: Wednesday Regular Edition**:
  - `window_end` = Wednesday 12:00:00 PM America/New_York.

### STEP 3: 4-Point Verification Gate & Epistemic Annotation
Evaluate every candidate story through the 4 sequential verification gates:

```python
def evaluate_candidate(candidate, window_start, window_end):
    # 1. Source Check (Tier 1 = 100, Tier 2 = 75, Tier 3 = 40)
    source_score = get_source_tier_score(candidate.primary_source_url)
    if source_score < 50:
        return {"verdict": "QUARANTINE", "reason": "Low source authority"}

    # 2. Cross-Check Gate (Surprising claim requires >= 2 independent sources)
    if candidate.is_surprising and candidate.independent_sources_count < 2:
        return {"verdict": "QUARANTINE", "reason": "Uncorroborated surprising claim"}

    # 3. Freshness Gate (Must be strictly inside window)
    if not (window_start <= candidate.published_at <= window_end):
        return {"verdict": "REJECT", "reason": "Outside research window bounds"}

    # 4. Hype & Buzzword Filter (Detect superlatives, deduct points)
    hype_score = calculate_hype_score(candidate.raw_text)
    if hype_score > 50:
        candidate.clean_text = strip_marketing_hype(candidate.raw_text)
        hype_score = calculate_hype_score(candidate.clean_text)

    # Composite Verification Score (0 - 100)
    composite = (source_score * 0.35) + \
                (min(candidate.independent_sources_count, 3) / 3 * 100 * 0.30) + \
                (100 * 0.20) + \
                ((100 - hype_score) * 0.15)

    if composite >= 80:
        return {"verdict": "PASS", "composite_score": composite}
    else:
        return {"verdict": "QUARANTINE", "composite_score": composite}
```
